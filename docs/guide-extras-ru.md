# Автообновление доп. модов (один раз настроить)

Сборка Prominence II у тебя уже импортирована в лаунчер. Доп. моды (Figura и всё, что добавим потом) будут подтягиваться сами при каждом запуске игры.

## Настройка (5 минут)

1. Скачай скрипт: https://raw.githubusercontent.com/danciksaparbekov-arch/mc-packs/main/client/setup-extras.ps1 (правой кнопкой → «Сохранить как…», например на рабочий стол).
2. Закрой лаунчер. Открой PowerShell в папке со скриптом и запусти:
   ```
   powershell -ExecutionPolicy Bypass -File setup-extras.ps1
   ```
3. Выбери номер своей сборки Prominence II из списка. Скрипт скачает установщик, один раз синхронизирует моды и **скопирует в буфер обмена команду**.
4. Открой лаунчер → сборка → **Настройки сборки → Launch hooks (Хуки запуска) → Pre-launch** → вставь команду (Ctrl+V) → сохрани.

Дальше при каждом запуске игры новые моды скачиваются сами, убранные — удаляются.

## Figura (аватары)

После настройки Figura уже будет в `mods`. Остаётся: Figura → настройки → **Figura Cloud IP** → `figura.shsr.ru`.

## Если что-то не так

- Игра не запускается после настройки → убери команду из Pre-launch и напиши Даниславу.
- Моды не появились → запусти `setup-extras.ps1` ещё раз и приложи вывод.
- Нужна Java 17 — она есть в лаунчере; скрипт её находит сам.
