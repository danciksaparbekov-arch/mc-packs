# Сладкий Баклажанчик — как начать играть

Один раз настроить (≈5 минут), дальше просто запускаешь игру и заходишь — моды обновляются сами.

## 1. Поставь сборку (если ещё нет)

1. Открой лаунчер (AstralRinth или Modrinth App) → поиск → **Prominence II: Hasturian Era**.
2. Выбери версию **v4.1.8** (не «последнюю»!) и установи.
3. Запусти игру **один раз** до главного меню и закрой.

## 2. Установи автообновление

1. Скачай файл **install.bat**:
   https://github.com/danciksaparbekov-arch/mc-packs/releases/latest/download/install.bat
2. Закрой лаунчер и **дважды кликни** по `install.bat`.
   (Если Windows спросит «защитник предупреждает» → «Подробнее» → «Выполнить в любом случае» — файл от Даниса.)
3. Подожди, пока скачаются моды. В конце появится 4 шага — в лаунчере:
   **сборка → шестерёнка → Launch hooks → поле Pre-launch → вставить (Ctrl+V)**.
   Команда уже в буфере обмена.

Всё. Больше ничего делать не нужно — Figura (аватары) тоже уже настроена.

## 3. Играй

- Адрес сервера: `sladkiybaklazhanchik.exaroton.me:45698`
- Аккаунт: Ely.by (как и раньше).
- Сервер выключается сам, когда никого нет. Включить: бот в Telegram **@sladkiy_baklazhancik_bot** → кнопка «▶️ Запустить» (подожди ~1,5 минуты).

## Бот в Telegram

- «📊 Статус» — работает ли сервер и кто онлайн.
- «▶️ Запустить» / «⏹ Остановить» / «🔄 Перезапустить».
- Хочешь новый мод? Пришли боту ссылку: `/add https://modrinth.com/mod/название` — Данис одобрит, и мод появится у всех.

## Эмоции (по желанию)

Скачай **install-emotes.bat** и запусти его:
https://github.com/danciksaparbekov-arch/mc-packs/releases/latest/download/install-emotes.bat

Больше ничего делать не надо: скрипт сам скачает эмоции (около 55 МБ), найдёт твою сборку Prominence II и положит их в папку `emotes`. Перезапусти игру. В игре эмоции открываются клавишей **B**.

Если GitHub не открывается, Данис пришлёт эмоции в Discord файлами `emotes-SPE-01of09.zip` … `emotes-SPE-09of09.zip`: скачай **все** в папку «Загрузки» и запусти тот же `install-emotes.bat`, он найдёт их сам.

## Если что-то не так

- Игра не запускается после настройки → в лаунчере очисти поле Pre-launch и напиши Данису.
- В меню Figura «failed to verify» → Figura → настройки → Network → Figura Cloud IP → `figura.shsr.ru`.
- Моды не появились → запусти `install.bat` ещё раз; если пишет про Java — запусти игру один раз и повтори.
